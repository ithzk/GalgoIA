# Base de conocimiento de GalgoAI

Pon aquí los documentos OFICIALES del ITT en formato `.md` o `.txt` (uno por tema):
servicio social, créditos complementarios, residencia profesional, titulación,
reinscripción, calendario escolar, etc.

Formato sugerido:

    # Servicio Social
    categoria: Trámites

    Requisitos:
    1. ...

Luego ejecuta `node scripts/ingest.mjs` (ver SETUP.md). El bot SOLO responderá con lo que esté aquí;
si falta información, dirá que no la tiene y remitirá al departamento correspondiente.
